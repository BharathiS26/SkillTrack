SkillTrack - how to run

1. Install JDK (not just JRE). Check:  javac -version   and   java -version
2. Open this folder in VS Code, open the terminal (Ctrl + `)
3. pip install -r requirements.txt
4. python app.py
5. Open http://127.0.0.1:5000
